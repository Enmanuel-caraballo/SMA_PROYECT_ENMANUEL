 11. PROBLEMAS COMUNES
----------------------------------------------------------------------
# "No module named 'greenlet'" (o cualquier otro módulo)
pip install greenlet          # o el nombre que diga el error

# El ESP32 no aparece en Herramientas -> Puerto
#   -> cable USB de datos + driver CP210x (Administrador de dispositivos)

# Arduino: "cannot specify '-o' with '-c'..."
#   -> Gestor de tarjetas -> esp32 -> instalar versión 2.0.17

# ESP32: "Conectando a Mosquitto... falló"
#   -> ¿Mosquitto corriendo? ¿IP_BROKER es la IP actual del PC (ipconfig)?
#   -> ¿mosquitto.conf tiene "listener 1883 0.0.0.0" y "allow_anonymous true"?
#   -> Firewall de Windows: permitir Mosquitto en redes privadas

# Agentes: "no pude conectarme a Mosquitto"
#   -> arrancar Mosquitto antes que los agentes

# Panel: el accidente no hace nada
#   -> ¿ya salió "Los 7 agentes del SMA están activos"? Los eventos enviados
#      antes de que los agentes terminen de arrancar se pierden.
# Panel: un cruce aparece "sin señal"
#   -> no está corriendo el simulador (o el ESP32 para cruce1)
# Vista 3D lenta
#   -> cerrar otras pestañas; si baja de ~24 FPS el brillo neón se apaga solo.
# Al cerrar los agentes quedan procesos de Python sueltos (servidor XMPP de SPADE)
#   y la próxima vez no arrancan: cerrar todo lo del proyecto con
Get-CimInstance Win32_Process -Filter "Name='python.exe'" | Where-Object { $_.CommandLine -match 'sma_agentes|simulador_ciudad|servidor_panel|multiprocessing' } | ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
